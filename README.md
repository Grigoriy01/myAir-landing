# Air — Strategic Agency Landing Page

A responsive landing page for **Air**, a full-service creative and strategic agency, built with **semantic HTML5**, **modular SCSS (BEM)**, and **Swiper.js**.

🔗 **[Live Demo](https://grigoriy01.github.io/myAir-landing/)**

---

## Features

- **Interactive Hero Slider:** Powered by **Swiper.js** with custom navigation controls, autoplay, and infinite loop.
- **Responsive Multi-Breakpoint Layout:** Tailored for mobile, tablet (`640px+`), small desktop (`1024px+`), and wide desktop (`1600px+`) viewports.
- **Pure CSS Mobile Drawer:** Slide-out navigation menu with `backdrop-filter: blur()` and animated hamburger-to-close icon driven by CSS state (`:checked`).
- **Modular SCSS Architecture:** Organized with reusable mixins, placeholders (`@extend`), variables, and isolated BEM blocks.
- **Custom Visual Details:** Staggered process cards using CSS custom properties (`--process-shift`), decorative avatar backdrops, and smooth hover transitions.

---

## Tech Stack

- **HTML5:** Semantic sectioning and accessible form controls.
- **SCSS (Sass):** BEM methodology, custom mixins, placeholders, and responsive grid/flex layouts.
- **JavaScript (ES6+) & Swiper.js:** Carousel initialization and mobile navigation state cleanup.
- **Parcel:** Zero-config bundler for development and production builds.
